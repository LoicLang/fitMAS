# Natation — Connaissances entraînement

## Modèle de zones (CSS — Critical Swim Speed)

- Z1 (Récupération) : CSS + 15-20s/100m — très facile, éducatifs, retour au calme
- Z2 (Endurance aérobie) : CSS + 5-10s/100m — séries longues régulières
- Z3 (Seuil / CSS) : allure CSS ±2s — clé de la progression, zone de travail principale
- Z4 (VO2max) : CSS - 5-10s/100m — séries courtes très intenses
- Z5 (Sprint) : vitesse max, 25-50m — puissance neuromusculaire

## Test CSS

- Protocole : 400m all-out puis repos 10min puis 200m all-out
- Calcul : CSS = (400 - 200) / (temps400s - temps200s) en m/s
- Convertir en allure /100m pour la pratique
- Retester toutes les 4-6 semaines
- Conditions : échauffement 400m avant, piscine 25m ou 50m (noter laquelle)

## Séries CSS (Z3 — seuil)

- Format : 6-10x100m à allure CSS, repos 15-20s
- Débutant : 6x100m R20s, progresser en nombre
- Intermédiaire : 8x100m R15s ou 4x200m R20s
- Confirmé : 10x100m R15s ou 5x200m R15s ou 3x300m R20s
- Clé : régularité absolue — chaque 100m au même temps (±1s)
- C'est LA séance qui fait le plus progresser en natation

## VO2max (Z4)

- Format court : 8-12x50m plus rapide que CSS (-5-10s/100m), R20-30s
- Format moyen : 4-6x100m allure soutenue, R30s
- Débutant : 6x50m R30s
- Confirmé : 6x100m R20s
- Fréquence : 1x/semaine max
- Cumul Z4 dans la séance : 400-800m max

## Endurance (Z2)

- Séries longues : 4-6x200m ou 3-4x400m à CSS+5-10s, R20-30s
- Régularité : chaque longueur au même rythme
- Constitue 60-70% du volume de séance
- Respiration : bilatérale recommandée (tous les 3 temps)
- Varier les nages : crawl principal, dos en récup, brasse si maîtrisée

## Éducatifs techniques

- Rattrapé (catch-up) : améliore l'extension et la glisse
- Bras mort : un bras le long du corps, l'autre nage — rotation et propulsion
- Pull buoy : isoler le haut du corps, travailler le tirage
- Plaquettes (petites) : renforcement propulsion — avec modération (<20% du volume)
- Water polo : tête hors de l'eau, renforce le gainage aquatique
- Battements : avec planche, 4-6x50m, travail des jambes
- Ondulations : 4-6x25m subaquatique, gainage et propulsion globale
- Placement : en échauffement ou en fin de séance

## Progression distance

- Augmenter le volume total de 200-300m par semaine max
- Débutant : commencer à 1000-1500m par séance
- Intermédiaire : 2000-3000m par séance
- Confirmé : 3000-4500m par séance
- 3 séances/semaine minimum pour progresser significativement
- 2 séances/semaine = maintien

## Technique sous fatigue

- Si le geste se casse (coude qui tombe, glisse qui disparaît) : réduire la série
- Mieux vaut court et propre que long et dégradé
- Fatigue technique ≠ fatigue cardio — apprendre à distinguer
- Signal d'arrêt : si l'allure dérive de >3s/100m sur 2 reps consécutives

## Structure séance type

- Échauffement : 200-400m varié (crawl, dos, éducatifs, battements)
- Corps de séance : 1-2 séries principales (CSS, VO2max, ou endurance)
- Retour au calme : 100-200m facile (dos, brasse, souple)
- Durée totale : 45-75min (1500-3500m selon niveau)

## Matériel

- Pull buoy : isoler le haut du corps — utile 1-2x/semaine
- Plaquettes (petites) : force de propulsion — max 15-20% du volume
- Palmes courtes : travail cardio et battements — idéal pour éducatifs
- Tuba frontal : travailler la technique sans la contrainte de la respiration
- Élastique chevilles : forcer le gainage et la flottaison
- Ne pas devenir dépendant du matériel : nager au moins 50% sans accessoire

## Eau libre (spécificités)

- Navigation : repérage régulier (tous les 6-8 cycles), water polo pour voir
- Drafting : dans les pieds ou sur la hanche du nageur devant
- Combinaison : flottabilité améliorée, s'entraîner avec avant la compétition
- Respiration : adapter le côté selon les vagues/le vent
- Transition piscine → eau libre : 2-3 séances minimum avant compétition
