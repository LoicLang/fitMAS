# Project Overview

## Etat actuel

`FitMAS` est en phase de bootstrap.
Le repository contient surtout l'environnement Python et les conventions de travail.

## Hypotheses visibles dans le repo

Les hypotheses suivantes viennent du contexte actuellement present:

- le projet semble s'appuyer sur Python
- une base SQLite locale est prevue en developpement
- une base PostgreSQL est envisagee en environnement cloud

Ces hypotheses doivent etre confirmees ou corrigees des que le produit est precise.

## Direction de travail

Avant de construire le produit, on veut poser:

- un repo lisible
- une documentation courte mais fiable
- des conventions simples pour les futurs agents et developpeurs

## Regle pratique

Si une decision produit ou architecture devient importante, elle doit quitter la conversation et entrer dans `docs/`.
